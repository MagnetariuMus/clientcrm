# ClientCRM — клиенттерді тіркеу жүйесі

Курстық жоба: «Клиенттерді тіркеу жүйесіндегі бағдарламалық ақауларды анықтау және түзету».
Авторы: Толқынұлы Еділ.

## Нені істей алады

- Клиентті тіркеу (аты-жөні, email, телефон, туған күні, қала, түрі)
- Валидация: email форматы, телефон пішімі, атының ұзындығы, туған күн аралығы,
  қайталанатын email-ге тыйым
- Тізімді беттеу (8 жазбадан), сұрыптау (атауы, күні, туған күні)
- Іздеу: аты, email, телефон, қала, ID бойынша, регистрге тәуелсіз
- Сүзгілер: клиент түрі және қала (бірге қолданылады)
- Жазбаны өңдеу және растау арқылы өшіру
- Статистика: барлығы, VIP, айлық тіркелу, қалалар саны
- CSV файлына экспорт (Excel үшін BOM-мен)
- Қазақ/орыс тілдері, таңдау браузерде сақталады
- Мобильді құрылғыларға бейімделген интерфейс
- Деректер `localStorage`-та (`crs_clients_v2` кілті) сақталады

## Іске қосу

1. Ең қарапайым тәсіл — `index.html` файлын браузерде ашу.
2. Немесе Node.js ортасында:

```bash
cd site
node server.js
# браузерде: http://localhost:5173
```

Сыртқы кітапханалар қажет емес (тек Node.js 18+).

## Файлдар

```
site/
├── index.html          # бет қаңқасы
├── assets/
│   ├── styles.css      # стильдер және бейімделген орналасу
│   └── app.js          # барлық логика (валидация, іздеу, CRUD, i18n)
├── server.js           # файлдарды беретін шағын HTTP сервер
├── mobile-preview.html # мобильді нұсқаны көрсетуге арналған қаңқа
└── package.json
```

## Демо режимдер (скриншоттар мен тексеру үшін)

| Параметр | Әрекеті |
| --- | --- |
| `?demo=add` | Жаңа клиент формасын ашады |
| `?demo=edit` | Бірінші жазбаны өңдеуге ашады |
| `?demo=delete` | Өшіруге растау терезесін ашады |
| `?demo=invalid` | Қате деректермен форманы жіберіп, валидацияны көрсетеді |
| `?demo=search&q=Асқар` | Іздеуді орындайды |
| `?demo=empty` | Нәтиже жоқ күйді көрсетеді |
| `?demo=selftest` | 8 сценарийді автоматты тексереді (нәтиже 8/8) |
| `?lang=ru` | Интерфейсті орыс тілінде ашады |
| `?noanim=1` | Анимацияларды өшіреді (скриншотқа ыңғайлы) |

## Деректерді қалпына келтіру

Төменгі колонтитулдағы «Демо деректерді қалпына келтіру» сілтемесі 14 демо-клиентті
қайта жасайды. Барлық деректерді тазалау үшін браузердің DevTools → Application →
Local Storage бөлімінен `crs_clients_v2` кілтін жою жеткілікті.
